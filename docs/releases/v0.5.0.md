# KartPad 0.5.0

Android **code135**, iPhone/iPad **build59**, and Apple Silicon Mac **build59**
are supplied together in this release. Apple TV retains its earlier separate
experimental preview.

## Downloads

| Platform | Installable package |
| --- | --- |

| iPhone / iPad | `KartPad-v0.5.0-ios-unsigned.ipa` — re-sign before installation |

Download `SHA256SUMS.txt` to verify your package. The source archive and notices

private signing material are not included.

## Changes

- **Auto-accelerate can be turned off.** On Android, open Controls → Touch
  Control Settings → Auto-accelerate. OFF restores ordinary A press, hold and
  release; ON keeps the one-second hold-to-latch behavior. The choice persists.
  iPhone and iPad also have the opt-out.
- **Generated vehicle thumbnails retain their colors.** Texture copies wait
  for complete shader draws, including copies spanning a full staging buffer.
  This repairs two reproduced paths that could retain black or incomplete
  images. The owner confirmed the Android correction.
- **Framebuffer-copy and startup crash fixes.** Copy pipelines match their
  destination format, fixing the reproduced iPad gameplay abort. Speculative
  shader replay is bounded to reduce startup compiler pressure. Partial
  graphics initialization cleans up safely and preserves the first error.
- **Android controller assignment is consistent.** Removed duplicate input
  routes, respected Unassigned, and synchronized player assignment between
  controller settings screens.
- **Renderer and readback corrections.** Fixed primitive boundaries, stale
  vertex data, index bounds, full-buffer admission and delayed readback
  callback ownership. Android also handles missing optional Vulkan debug
  functions and a separate SwiftShader initialization failure.
- **Ghost export explains invalid records** instead of silently treating all
  validation failures as an empty license.

## Updating

Install over the existing app with the same bundle identifier and signing
identity. Preserve your game files, licenses, Miis and saves; do not uninstall
or clear storage as an update step. See the [Android](../INSTALL_ANDROID.md),
[iPhone/iPad](../INSTALL_IPA.md), and [Mac](../INSTALL_MACOS.md) guides.

## Known limitations

This release does not establish universal 60 FPS or compatibility with every
GPU. Device-specific geometry reports, PowerVR capability limits, warmed-device
slowdowns, Retro menu pacing, Mac Wii Remote/Classic Pro delays, and the original
ghost-discovery report remain unresolved.

An older Retro license can still return console-serial mismatch (22005) while
another license works. This behavior predates these builds; the tested iPad's
persisted identity is unchanged. Do not delete licenses or rotate console
identity as a workaround.

The fixes have negative-control reproductions, production-source sanitizer
checks, actual renderer pixel tests with validation enabled, and package and
symbol identity checks. The owner confirmed the Android thumbnail correction;
this does not establish full online endurance or acceptance on every Apple or
Android device. Detailed scope and device results are in the
[verification record](v0.5.0-readiness.md).

Compiled application source is `a2f41d5`; the source archive preserves that exact
parent and maintained runtime pins. Later release-documentation and packaging
commits are identified separately. See [source and rebuild details](v0.5.0-source.md).
