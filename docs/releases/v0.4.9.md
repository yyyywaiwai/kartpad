# KartPad 0.4.9

This build fixes Apple mobile controller registration for local multiplayer
(issue #85), adds visible Player 1–4 assignments and face-button remapping on
iPhone/iPad, and provides multiplayer guidance and experimental private Wii-server
configuration across the Apple interfaces.

- WPAD connection probes now recognize physical players without consuming the
  short A press used to register them. Controller callbacks sample immediately.
- The Mac app now uses the same K-circuit icon artwork as iPhone/iPad.
- The Multiplayer menu covers Original Mario Kart Wii and Retro Rewind. It
  explains local split-screen and the game's private friend-room flow.
- A private Wii-server hostname can be saved for the next launch. This is
  experimental scoped client routing, not a hosted server or verified Original
  Mario Kart Wii online service. Exact backend authentication and race acceptance
  remain open.
- DualShock 4/DualSense use the existing Extended Gamepad path. Controller Setup
  explains PlayStation button positions and allows face-button remapping.
  Original GameCube USB adapters are not supported on iPad by this update.

MeleePad-style room codes, native host/join, traversal, ready state and peer chat
are not included. See [Multiplayer and controllers](https://github.com/chrissotraidis/kartpad/blob/main/docs/MULTIPLAYER.md) for the
precise supported paths, private-server contract and Android handoff.

The Apple TV build remains experimental. Android implementation is paused and
has not been merged, built or released as part of this update. Builds and
snapshot-controller tests do not replace physical multiplayer acceptance.

Game data is not included. The IPAs must be re-signed locally. No disc image,
extracted game assets, saves, signing identity or provisioning profile is
redistributed. Retro Rewind remains pinned to 6.12.7.
