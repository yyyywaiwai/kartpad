# KartPad 0.4.23 source delivery

The source bundle includes the exact Android compilation source at `6dccb23569a5c770aa883947ef7127e985ccd0c3`, its maintained runtime gitlinks, pinned upstream snapshots, and the exact prepared Android runtime. It also contains the recorded iOS base source at `91aaedc7cff6c4e801cfe0636d5c3a4aa3b9bc2d`, the prepared iOS runtime, and the release packaging/refresh scripts.

Android is rebuilt from maintained source with the new launcher and identity repair. iOS is an incremental build retaining the accepted base runtime and translated game objects, freshly compiling the launcher and Mii manager and compiling the HD assets. The manifests distinguish these compilation histories; neither the base iOS source nor binary is relabeled as a full build from current main. See [the iOS rebuild recipe](v0.4.23-ios.1-source.md).

The dependency archives from the reviewed 0.4.22 delivery are preserved and checked against their file manifest. Every file in this delivery has a size and SHA-256 entry in SOURCE-MANIFEST.json. The manifest binds the Android APK and identifies both platform source inputs.

Game images, generated game translations, saves, console identities, and signing keys are excluded. Rebuild with your own supported game inputs and platform SDKs. The core snapshot includes offline Git restoration metadata for its pinned dependencies.
