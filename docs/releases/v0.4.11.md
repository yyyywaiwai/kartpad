# KartPad 0.4.11 — important online console-identity correction

**Update before using Retro WFC on iPhone or iPad.** This rebuild includes the
upstream console-serial correction reported by **patchzyy** in
[issue #94](https://github.com/chrissotraidis/kartpad/issues/94).

The old `SCGetProductSN` override wrote a string where the game expects a
four-byte number. Different serials sharing their first four digits could
therefore send the same online CSNum; the write could also overwrite adjacent
guest memory. The reference server uses overlapping CSNum history when matching
bans, creating a risk of collateral bans. This finding does not prove that any
particular player was banned.

We backported [upstream e0e362b](https://github.com/patchzyy/Wiicompiled/commit/e0e362bd992e07784f8ce7fa795cdb496af7b075)
and rebuilt the native app. The correction parses the complete numeric serial,
validates the four-byte output and writes it in guest byte order. Tests reproduce
the old collision and verify corrected distinct values, adjacent-memory safety,
malformed-input rejection and bounds. This is a narrow, credited fix, not an
unreviewed update to all upstream changes.

## Downloads and update safety

- `KartPad-v0.4.11-ios-unsigned.ipa`: iPhone/iPad **0.4.11, build 26**. Re-sign
  with the same identity and bundle identifier and update in place. Back up
  saves and retain your owned game image; do not uninstall or clear the app.
- `SHA256SUMS`: verify the downloaded IPA before signing.
- Android's corrected APK is available separately in
  [v0.4.10-android.1](https://github.com/chrissotraidis/kartpad/releases/tag/v0.4.10-android.1).

The fix does **not** regenerate console identities, change friend codes, delete
licenses or reset progress. It also cannot remove incorrect CSNums already
stored in a server's account history or reverse an existing ban. Affected
profiles may need service-admin cleanup and collateral-ban review; changed-IP
login can also encounter server identity checks. Do not delete saves, regenerate
identities or create replacement accounts as a workaround.

Existing iPhone/iPad downloads through v0.4.10, Mac v0.4.9 and the old tvOS
binary lack this fix. Keep those binaries offline until updated. The corrected
Mac rebuild is now available in
[v0.4.11-macos.1](https://github.com/chrissotraidis/kartpad/releases/tag/v0.4.11-macos.1).
This release's IPA remains the original verified iPhone/iPad artifact; the
follow-up Mac build has its own exact-source tag. Old tvOS still needs rebuilding.

## Content and validation boundary

The IPA includes compiled ahead-of-time game logic and the required notices,
but no disc image, extracted retail assets, Retro Rewind pack, saves, private
signing identity or provisioning profile. Supply your own supported PAL RMCP01
revision 0 image. Audits establish the stated package boundary, not that the
binary is copyright-free or that game-derived redistribution rights are cleared.
KartPad's GPLv3 licensing and Corresponding Source obligations remain in effect.

The release retains the existing controls/layouts and data-management flows.
Host/ARM64 regression tests and rebuilt-package validation do not establish
production-server history cleanup or a complete new physical online race.
