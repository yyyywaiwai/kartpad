# KartPad 0.4.15 for iPhone and iPad

Build 34 adds diagnostic-log review before opening a GitHub report. Review the saved log, check the acknowledgment, then attach the file manually on GitHub. If you cannot attach a log, explain why; that explanation is included in the draft. No log is uploaded automatically.

Requires iOS/iPadOS 16 or newer on ARM64. The public IPA is unsigned and requires your own signing. Existing game files, saves and settings remain in the app data container during an in-place update.

Retains the 0.4.14 chooser and Metal surface lifetime correction. This update does not claim a new gameplay, performance, external-display or graphics fix.
