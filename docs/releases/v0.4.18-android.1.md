# KartPad 0.4.18 for Android — code 83

Choose **Preferred Game…** on the KartPad selector to start Original or Retro
Rewind automatically on a fresh launch. **Ask Every Time** remains the default.
KartPad still checks game data first, and returning to the KartPad menu keeps
the selector open. Changing the preference applies on the next launch.

This release also corrects generated Kamek return handling for Retro Rewind
hooks that skip ahead after returning, while reducing repeated generated
continuation code. The reported exact `0x807EF16C` crash and Item Rain-specific
acceptance remain tracked in #248; this is not a blanket claim that all Retro
crashes are fixed.

The D-pad Show/Hide editor correction, FPS counter sizing, and R/D-pad Up
controller mappings were already shipped in **0.4.17 / code 80** and remain
included. Closing their completed support requests did not create a separate APK.

## Validation

The owner’s Pixel was updated in place from private code 79 to the combined
private code 82 candidate after a full backup verified against 6,319 protected
file hashes. Every protected file matched immediately after installation.
Original/Retro preferred launch, saved choice, and return-to-menu behavior
passed on the phone. Saves, licenses, identity and existing settings were
unchanged after these UI/startup checks. The owner then reported that the game
works; no specific Item Rain, completed-race count or online result is inferred.

Code 83 is the public release package of the tested wrapper and native runtime.
Its public signer is compatible with prior public APKs and differs from the
private device test signer. Artifact/provenance, signature, source delivery and
hosted-download verification are recorded in the release evidence.

WFC menu latency, online disconnects, GPU-specific rendering/performance reports,
and automatic Retro Rewind updating remain separate open work. This Android
release does not contain a new iOS 27 crash fix or publish the Mac VSync candidate.
