# KartPad 0.5.1 experimental 1 — Apple build60

This is a temporary experimental mitigation while we collect more evidence about
slowdowns reported after 0.5.0. It is **not a confirmed fix for all slowdowns or
crashes**, including the iPad report of exits after approximately ten minutes.

The public iPhone/iPad 0.5.0 IPA accidentally enabled diagnostic-candidate mode,
forcing renderer validation, robustness checks and function timing on. This build
disables that forced diagnostic mode. Build wrappers now default it off, package
auditing checks the final value, and the session log records whether it is on.
The renderer correctness fixes from 0.5.0 are retained.

Downloads:
- iPhone/iPad: unsigned IPA, version 0.5.1/build60. Re-sign with your existing
  compatible signing identity and install over the existing app.
- Apple Silicon Mac: app ZIP, version 0.5.1/build60. The forced iOS diagnostic
  mode does not apply to macOS; this companion experimental build does not claim
  a Mac performance fix.
- Android 0.5.0/code135 is not affected by this automatic iOS diagnostic switch.
  No replacement APK is included. User-enabled Renderer Validation and older
  explicitly named diagnostic previews are separate.

Keep your saves and game files. Do not uninstall or clear data. If signing is
incompatible, stop rather than delete the installed app. This release supplies
no game images, saves or signing identities.

If you try this build, please report the exact build/device and whether the same
course/effect is better, unchanged or worse. Matching frame-time evidence and a
redacted crash excerpt remain useful. Do not upload game data or full private
archives. No universal FPS or crash-resolution claim is made.
