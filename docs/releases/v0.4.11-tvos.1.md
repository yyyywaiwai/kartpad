# KartPad 0.4.11 — experimental Apple TV console-identity correction

This **tvOS 17+ ARM64, version 0.4.11/build 9** rebuild brings the credited
console-serial fix to the remaining Apple TV distribution. Update before
testing Retro WFC. Apple TV remains experimental; this release does not claim
new physical gameplay, networking, DSU controller, or external-display acceptance.

Thanks to **patchzyy** for reporting [#94](https://github.com/chrissotraidis/kartpad/issues/94)
and supplying [upstream e0e362b](https://github.com/patchzyy/Wiicompiled/commit/e0e362bd992e07784f8ce7fa795cdb496af7b075).
The old `SCGetProductSN` override wrote text into a four-byte numeric output,
collapsing different serials with a shared prefix and overwriting adjacent
guest memory. The corrected routine writes the full numeric serial in guest
byte order. The upstream dependency pin is otherwise unchanged.

Download `KartPad-v0.4.11-tvos.1-unsigned.ipa` and `SHA256SUMS`, verify
the checksum, and follow the included [installation guide](../INSTALL_TVOS.md).
Back up first and update in place with the same signing identity and bundle
identifier. Do not delete the app or reset its identity. tvOS may purge cache
storage, so retain a separate backup. An Extended Gamepad is still required.

This correction preserves console identities, friend codes, and saves. It
cannot erase an incorrect CSNum already retained in server history or reverse
an existing ban; those require service-admin review. Do not create replacement
identities/accounts to work around that problem.

The package includes no disc image, extracted game data, Retro Rewind pack,
saves, or signing material. Supply your own supported PAL RMCP01 revision-0
data. The unsigned IPA requires local re-signing. iPhone/iPad, Mac and Android
downloads remain at their separate corrected platform releases.
