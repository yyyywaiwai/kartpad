# KartPad Android 0.4.13 preview 1 — unstable testing build

For ARM64 Android phones and tablets, Android 9/API 28 or newer, with Vulkan.
Version code 28 uses the existing public release signer. Install over the
existing public Android APK to preserve app data; do not uninstall or clear
storage. Private builds with another signer need a separately planned migration.

This preview adds save-transfer safeguards and diagnostic evidence. Graphics
corruption, slowdown, online-menu stalls and successful online races remain
under investigation. It is not a verified fix for those issues.

## Changes

- **Restore Retro Ratings…** matches a PC `RRRating.pul` to online profile IDs
  in an already-restored Retro save. Restore the raw save, restart, then let
  Retro create its local rating file before choosing the matching companion.
  Apply occurs before gameplay, with a checked backup and selective merge.
  Both Retro save modes share ratings for the same online ID; unrelated records
  are preserved. Cancellation and completion use durable terminal records to
  prevent an old request replaying. Unsupported/custom NAND configuration is
  refused. This does not migrate Miis or synchronize server ratings.
- Private diagnostics include bounded source fingerprints and compatibility
  context, distinguish configured versus active renderer validation, and can
  observe unfinished network waits. Renderer Validation adds bounded samples
  from actual submitted draws. These observations help investigation; they do
  not establish the cause of a stall or graphics defect.
- Android scalar floating-point helpers avoid redundant exception-flag updates
  while preserving their computed values. Sustained device performance gains
  are not established.
- The chooser uses KartPad artwork and keeps it reachable in short landscape
  layouts. Existing fullscreen, import and profile-aware save features remain.

## Testing and limits

Keep a separate save backup. Start with offline Original/Retro launch and menu
checks. For rating transfer, verify the matching licenses and restored ratings
**offline** before attempting online play. Full Mii migration and real-save
acceptance remain pending. If staging or application reports failure, keep the
request/backups and report the error; do not clear app storage.

For an existing graphics or stall report, retain the same scene, resolution and
settings for comparison. Renderer Validation may reduce performance; turn it
back off after collecting the relevant diagnostic sample. Review exported
private diagnostics locally and share only relevant excerpts, not the complete
archive, game files, saves or identifiers.

The exact public-signer APK passes package, signature, permission, resource and
16-KiB alignment audits. The packaging owner's API 36 ARM64 emulator evidence
uses an alternate-signer APK derived from the same AAB, with identical ZIP
payload outside signing metadata: chooser, Original startup/menu and actual
DocumentsUI diagnostics export. Synthetic saved-state fixtures remained
byte-identical across that update. This is not physical acceptance, sustained
performance, complete Retro migration or online-race acceptance. The actual public-signer APK also passes a fresh install and chooser check in
a disposable emulator overlay, default validation-off/incomplete-data guard,
DocumentsUI disc-picker cancellation, and seeded Original startup/intro
rendering for at least 1201 frames. This is not a positive full-disc import
test. The original emulator disk and owner's Pixel remain unchanged; this APK
has not been installed on that Pixel.

Focused host verification passes 214 rating-storage checks, 52 format checks
and the existing save/identity suites. No Apple release or device acceptance is
part of this Android preview.
