# KartPad 0.4.23 for Android

A fresh racing launcher and clearer player identity controls.

- New shared HD KartPad icon and racing menu.
- Dark mode by default, with a persistent light-mode option.
- Choose a preferred game on launch and return to the launcher from the in-game menu.
- Repair a license whose linked Mii is missing with Choose Mii. Normal rename remains available for valid links.
- Identity actions are visible directly; detailed guidance lives under About Player Identity.

The owner accepted the new interface and game operation on Pixel 9 Pro XL. Android performance remains an active investigation; this release does not claim a general FPS, graphics, online, or cross-device stability fix. The private manual graphics-memory probe is not included in the public build; it did not run automatically. The public build retains the established emulated TLS behavior and Android 9 minimum.

Version 0.4.23-android.1, code 104, ARM64. Signed with the existing public release identity. Update in place; preserve saves and game data. A private development-signed installation cannot be replaced by a differently signed public APK in place; do not uninstall it to force the update.
