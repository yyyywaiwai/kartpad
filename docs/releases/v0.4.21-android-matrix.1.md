# Android character graphics comparison — code 91

Experimental APK for character corruption reported in #193. Normal rendering remains the default. This is not a confirmed graphics fix or an FPS update.

## What changed

The two character pipeline recipes identified in the report can now use literal matrix indexing while preserving each vertex’s matrix selection. A restart-only **Character Graphics Test** setting selects Normal, original indexing, or compatibility indexing. Both comparison modes use the same draw behavior and bounded diagnostics; they may run slower than Normal.

This build also includes the current reporting controls. Existing game data and identities are preserved by an in-place update using the same Community Release signing identity.

## Compare the affected scene

1. Open **Getting Started → Character Graphics Test** in the game chooser, or **Display → Character Graphics Test** in the game menu.
2. Save **Compare: original indexing**, fully close KartPad, reopen, and visit the affected character screen.
3. Repeat with **Compare: compatibility indexing**, then repeat original indexing once more. Keep the same character, mode, resolution and aspect ratio.
4. Report whether the corruption changes and share the report/log from each run. Matching `KartPadPNMTX draw_binding` lines establish whether the tested shaders were reached.
5. Return to **Normal** afterward. Do not use these comparison modes to judge performance.

## Validation and limits

Both actual original shaders are byte-identical to code 85. The alternate shaders pass local Dawn/Tint validation and matrix-selection equivalence checks. Native Android compilation, release packaging audits, and setting persistence/failure/activity-recreation checks passed. No affected Android GPU or physical gameplay acceptance is claimed. This is a prerelease comparison, not a replacement for stable code 85.

Version: `0.4.21-matrix.1`, code `91`, arm64. Public signing is compatible with prior Community Release APKs. Do not uninstall a differently signed private preview to force an update.
