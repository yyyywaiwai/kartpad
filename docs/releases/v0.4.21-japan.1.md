# KartPad v0.4.21-japan.1 — Retro Rewind 6.12.8

Japanese RMCJ01 revision-0 community preview for iPhone/iPad and Apple Silicon Mac.
App version: 0.4.21 (43). This fork's version is independent of upstream platform releases.

## Changes

- Rebuild the Japanese Original + Retro Rewind executable graph against the pinned official Retro Rewind 6.12.8 Code.pul.
- Fix error 22010 caused by compiling the old 6.12.7 graph while using the 6.12.8 pack.
- Reject stale or wrong-region Retro Rewind translation metadata before Japanese iOS builds.
- Verify Japanese runtime preparation by reproducing the regional transformation from pinned sources and validated local game data.
- Update SunPad snapshot verification for the upstream KartPad controller and diagnostics changes.

## Downloads and installation

- `KartPad-v0.4.21-japan.1-RMCJ01-ios-unsigned.ipa`: iOS/iPadOS 16+, ARM64. Re-sign with your own certificate and provisioning profile before installation.
- `KartPad-v0.4.21-japan.1-RMCJ01-macos-arm64.dmg`: Apple Silicon, macOS 14+. Drag KartPad Japan to Applications. Ad-hoc signed; not Developer ID signed or notarized.
- `KartPad-v0.4.21-japan.1-source.tar.gz`: source snapshot, including pinned runtime submodules and external source references.
- `SHA256SUMS`: checksums for the release assets.

Supply your own matching Japanese revision-0 game data and the official Retro Rewind 6.12.8 pack. PAL/RMCP01 and USA/RMCE01 are not included in this release. Keep regional app data separate. Back up saves before updating.

## Acceptance scope

The corrected development build was installed without deleting the existing app on a physical iPad Air M2. Retro WFC login succeeded and the online menu and player count were visible. The server displayed an UNSTABLE notice at that time. Online race completion was not tested. Public IPA signing remains the recipient's responsibility; the development provisioning profile is not distributed.

Mac packaging and signing checks are distinct from gameplay and online acceptance. No new Mac race or online acceptance claim is made here.

## Source and rebuild

Use this release tag and initialize submodules recursively. Restore the pinned external references from the source snapshot with the supplied `restore-source-git.py`, following `dependencies.lock.json`. Install Xcode, CMake, Ninja, Python, and the pinned .NET toolchain/dependencies documented in the repository.

With your own validated RMCJ01 DATA, official Retro Rewind 6.12.8 pack, and matching signed Japanese Retro WFC payload, run `scripts/translate-rmcj01-retro.sh` using a fresh `KARTPAD_RMCJ_BUILD_TAG`; then build the resulting graph with `scripts/build-rmcj01-ios.sh ... dual`. Do not reuse the older 6.12.7 translation tree. The generated graph is private and is not part of the source archive.
