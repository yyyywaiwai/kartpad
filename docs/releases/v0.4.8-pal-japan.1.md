# KartPad v0.4.8-pal-japan.1 — PAL / Japan community preview

## Downloads

Choose the archive matching your game region. These are separate regional
builds, not a single executable that switches between PAL and Japan.

| Region | macOS (Apple Silicon) | iOS / iPadOS (unsigned) |
| --- | --- | --- |
| Japan, RMCJ01 revision 0 | `KartPad-v0.4.8-pal-japan.1-RMCJ01-macos-arm64.zip` | `KartPad-v0.4.8-pal-japan.1-RMCJ01-ios-unsigned.ipa` |
| Europe / PAL, RMCP01 revision 0 | `KartPad-v0.4.8-RMCP01-macos-arm64.zip` | `KartPad-v0.4.8-RMCP01-ios-unsigned.ipa` |

The PAL archives are byte-identical copies of the original project's
[v0.4.8 release](https://github.com/chrissotraidis/kartpad/releases/tag/v0.4.8),
renamed to make the region explicit. They retain upstream provenance and
notices; they are not rebuilt with this fork's changes.

The Japanese archives contain the user-accepted Original / Retro Rewind
6.12.7 candidates. The app reports version 0.4.8 (22). Japan uses separate
app identifiers (`dev.kartpad.rmcj01.ios` and
`dev.kartpad.rmcj01.development`). The source implementation is commit
`c7669d422b4bc8fc12880f18cec36cff882f76f7`; this release adds packaging metadata
and preserves the tested machine-code sections. RMCE01 (USA) is not included.

## Installation

- macOS: Apple Silicon, macOS 14 or newer. Extract the ZIP and install the app.
  It is ad-hoc signed, not notarized with an Apple Developer ID certificate.
- iOS / iPadOS: version 16 or newer, ARM64. The IPA is unsigned and requires
  local signing with your own certificate and provisioning profile.
- Supply your own matching revision-0 game image / extracted DATA. Neither
  region's package contains a disc image or extracted game assets.
- Retro Rewind additionally requires the matching official 6.12.7 pack.
- Keep the regions' saves and data separate. Do not replace a PAL executable
  with the Japanese executable inside an existing app bundle.

## Validation and limits

The user accepted iPad/macOS validation. Assistant-observed boot, import,
replay, persistence, Retro WFC login and room evidence, as well as the earlier
room-join timeouts and other unverified flows, remain documented in
[the extended ledger](../RMCJ01-EXTENDED.md). This preview does not assert that
the assistant independently completed a two-client online race. iPhone and
Apple TV testing and course-by-course verification were explicitly excluded.

Source regression checkpoint: 104 Python tests (103 passed, one private PAL
payload-cache test skipped) and 16/16 native CTests. Japanese package audits,
unsigned-IPA content inspection and SHA-256 integrity checks are performed
before upload. The default-off network trace setting does not change routing.

## Distribution boundary

These free community-preview apps contain ahead-of-time translated executable
logic, but no game image, extracted assets, Retro Rewind pack, saves, account
identity, device identifiers, private signing key or provisioning profile.
The iOS signature is removed; the Mac signature is ad-hoc. Available license
notices and provenance are included. This release does not establish rights
in Nintendo material or third-party code; see `RIGHTS_AND_LICENSES.md`.

`SHA256SUMS` covers all four downloadable app archives. PAL assets preserve
their original upstream bytes; Japanese assets are packaged from the tested
candidates without distributing their private signing or runtime state.
