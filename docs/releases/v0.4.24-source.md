# KartPad 0.4.24 source delivery

`KartPad-v0.4.24-source.tar.gz` covers both mobile packages. `SOURCE-MANIFEST.json` binds every member by SHA-256 and size and records the app artifact hashes. The core snapshot identifies the exact Android compilation commit, with recursive pinned source submodules. Release tools and documentation are supplied separately; later packaging commits do not relabel the compiled source.

The `retained-base/` snapshot includes the exact iOS base and pinned upstream/Dolphin source; use its restoration manifest when rebuilding the base.

The archive retains the reviewed dependency archives and recorded iOS base source/prepared runtime from the prior delivery, verifies every retained file, and replaces the prepared Android runtime with its fingerprint-checked compilation input. The maintained iOS settings-overlay source in the core snapshot supplies the refreshed FPS unit. See [iOS composition](v0.4.24-ios.1-source.md).

Extract the core snapshot and use its restoration metadata to reconstruct Git identities offline. Follow its build instructions with the documented SDKs and your own supported game data. Generated game translation, disc images, saves and signing material are not included. Dependency reconstruction notes may retain older release labels because those dependencies were unchanged. Exact artifact hashes are audit identities; different toolchains need not reproduce identical bytes.
