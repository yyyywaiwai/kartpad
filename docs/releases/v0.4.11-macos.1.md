# KartPad 0.4.11 — Apple Silicon Mac console-identity correction

**Update before using Retro WFC.** This native macOS 14+ ARM64 rebuild contains
the same credited upstream console-serial correction shipped for iPhone/iPad
in [v0.4.11](https://github.com/chrissotraidis/kartpad/releases/tag/v0.4.11) and
Android in [v0.4.10-android.1](https://github.com/chrissotraidis/kartpad/releases/tag/v0.4.10-android.1).
The Mac app version is **0.4.11, build 26**. The separate platform tag records
its exact source without moving the already published iPhone/iPad release tag.

Thanks to **patchzyy** for reporting [#94](https://github.com/chrissotraidis/kartpad/issues/94)
and supplying [upstream e0e362b](https://github.com/patchzyy/Wiicompiled/commit/e0e362bd992e07784f8ce7fa795cdb496af7b075).
The old override copied a serial string into a four-byte numeric output,
collapsing different serials with a shared prefix into one online CSNum and
overwriting adjacent guest memory. The reference server matches CSNum history
when applying bans, making this a serious collateral-ban risk. The new helper
validates and writes the complete numeric serial in guest byte order.

## Download and update

- `KartPad-v0.4.11-macos.1-arm64.zip`: ad-hoc-signed Apple Silicon app, not a
  notarized Developer ID release. Verify it against `SHA256SUMS` before opening.
- Quit the old app, back up important saves, and replace only `KartPad.app`.
  Keep your Application Support folder and supported owned game-data folders.
  Do not disable Gatekeeper globally; see the included installation guide.

Original and Retro Rewind 6.12.7 profiles, native menus, controller mapping and
player-identity management remain available. This is a focused correction on
current main, not a blanket upgrade of the upstream dependency pin or a claim
that platform-specific features have become identical.

The correction does not reset console identities, friend codes or progress.
Incorrect CSNums already retained by a service and any existing bans require
separate service-admin review. Do not wipe identities or create replacement
accounts to bypass those checks. Older Mac/iOS/Android binaries should remain
offline until updated. The old experimental tvOS binary still needs rebuilding.

## Package boundary

As in earlier Mac releases, the app contains compiled ahead-of-time translated
logic but no disc image, extracted retail assets, Retro Rewind pack, saves,
account data or private signing identity. Users supply their own supported PAL
RMCP01 revision 0 data and install the exact Retro Rewind pack separately.
GPLv3 and third-party notices are included. Audits verify the package boundary;
they do not establish redistribution rights in game-derived material.

Build, package and focused regression checks do not establish production-server
history cleanup, a complete new physical online race or new controller hardware
acceptance. Prior gameplay acceptance remains separate evidence.
