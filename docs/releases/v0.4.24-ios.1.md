# KartPad 0.4.24 for iPhone and iPad — build 49

The accepted mobile update brings consistent settings, Original Time Trial ghost transfers and clearer problem reporting.

- Matching Android/iOS menu order and labels, with Player Identity and Time Trial Ghosts directly under Game Data & Saves.
- Original `.rkg` import/export, validation, backup and deferred application that preserves intervening save progress. Retro Rewind custom-track ghosts remain unsupported.
- Expanded controller D-pad/trigger mappings, optional shared actions and an L1-for-items preset. Mapping and player setup have separate entries.
- Small/Medium/Large FPS counters; extracted-folder import opens a real folder picker.
- Scrollable, keyboard-aware problem reports with improved diagnostic context.
- Safer save export/restore across the supported license slots and clearer Retro Rewind management.

Includes yesterday's racing K icon and launcher, dark mode by default, light-mode toggle, preferred-game selection, return-to-menu navigation, and license rename/Choose Mii repairs.

The owner accepted the interface and game operation on the attached iPhone. iPad shares the universal UI and assets; this release is not a new physical iPad gameplay certification. No general FPS improvement or resolution of outstanding Android crashes, geometry corruption, screen tearing or existing online-identity failures is claimed.

Download the unsigned IPA, re-sign with your existing identity, and update in place. Game data is not included. See [installation](../INSTALL_IPA.md), [settings](../SETTINGS.md) and [source/rebuild details](v0.4.24-ios.1-source.md).
