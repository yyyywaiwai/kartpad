# KartPad Android 0.4.12-android.1 — save transfer and import testing update

This Android testing release adds explicit save-profile selection and fixes
incomplete disc imports. It is **version code 22**, signed with the same public
release identity as code 21. Install the APK over the existing public app;
never uninstall or clear storage to update. Apple builds are unchanged.

## Changes

- **Manage Saves…** now selects Original Mario Kart Wii, Retro Rewind, or Retro
  Rewind (Separate Save). Export and restore confirmations name the destination.
  The Android file-picker target survives activity recreation; an unknown target
  rejects the result. Each profile has its own staged restore and prior-save
  backup. A failed restore prevents startup until resolved.
- Disc import checks available storage before extracting, stops when any game
  file fails to extract, and reports storage exhaustion clearly. A failed
  reimport preserves the previously installed game data and removes its staging
  directory. Existing saves and identities are not reset.
- The issue #94 console-serial correction remains included. Historical server
  records or bans still require service-admin review.

For PC transfer, keep the original `rksys.dat`, export any existing destination
save first, choose the matching profile, then restore and restart. Verify the
expected licenses and progress offline. Save transfer does not include Miis or
console identity. Automatic synchronization is not implemented. See the
[save-transfer guide](https://github.com/chrissotraidis/kartpad/blob/v0.4.12-android.1/docs/SUPPORT.md#android-save-transfer).

## Validation and remaining limits

Host tests cover all three profiles, invalid inputs, isolated backups, conflicting
identity changes, interrupted publication and recovery. Android emulator tests
cover real AtomicFile storage and native document-picker targeting with activity
recreation enabled. The signed playable candidate completed a full supported
WBFS import and Original startup on an API 36 ARM64 Vulkan emulator. Low-space
preflight and forced exhaustion during reimport both fail safely; the complete
prior game-data tree remains byte-identical. All 140 Python tests and release
lint pass.

**Physical acceptance of this build and the reporter's PC Retro Rewind transfer
remain pending.** Earlier Pixel gameplay acceptance belongs to earlier builds.
This release does not fix reported Adreno geometry/texture corruption, frame
drops, Fill Screen distortion or external-display output. It does not promise
sustained 60 FPS. Shell profiling is disabled in this non-debuggable build;
existing local diagnostic exports remain available.

## Downloads

- `KartPad-v0.4.12-android.1-arm64.apk` — installable ARM64 Android app.
- `KartPad-v0.4.12-android.1-notices.zip` — notices, source provenance and guides.
- `SHA256SUMS` — verify both downloads.

Requires Android 9/API 28+, ARM64, Vulkan and your own supported PAL RMCP01
revision 0 game image. No disc image, extracted assets, Retro pack, save, private
translated source or signing keys are included. Compiled translated game logic
is included under the project's existing community-distribution boundary;
third-party rights remain unresolved. The AAB is kept local.

Private preview and self-built APKs with a different signer cannot receive this
as an in-place update. Preserve those installations and their data; do not
uninstall to bypass Android's signature check. Follow the
[installation guide](https://github.com/chrissotraidis/kartpad/blob/v0.4.12-android.1/docs/INSTALL_ANDROID.md).
