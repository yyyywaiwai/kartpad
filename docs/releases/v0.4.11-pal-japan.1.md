# KartPad v0.4.11-pal-japan.1 — PAL / Japan community preview

## Downloads

Choose the archive matching your game region. These are separate regional
builds, not a single executable that switches between PAL and Japan.

| Region | macOS (Apple Silicon) | iOS / iPadOS (unsigned) |
| --- | --- | --- |
| Japan, RMCJ01 revision 0 | `KartPad-v0.4.11-pal-japan.1-RMCJ01-macos-arm64.zip` | `KartPad-v0.4.11-pal-japan.1-RMCJ01-ios-unsigned.ipa` |
| Europe / PAL, RMCP01 revision 0 | `KartPad-v0.4.11-RMCP01-macos-arm64.zip` | `KartPad-v0.4.11-RMCP01-ios-unsigned.ipa` |

The PAL iOS archive is a byte-identical copy of the original project's
[v0.4.11 iPhone/iPad release](https://github.com/chrissotraidis/kartpad/releases/tag/v0.4.11),
renamed to make the region explicit. The PAL macOS archive is likewise copied
byte-for-byte from the original project's
[v0.4.11-macos.1 release](https://github.com/chrissotraidis/kartpad/releases/tag/v0.4.11-macos.1).
They retain upstream provenance and notices and are not rebuilt by this fork.

The Japanese archives are rebuilt from this release tag after merging upstream
`main` through commit `2774827a77695afe141e7b3c15b969075fdc7771`. The apps report
version 0.4.11 (build 26) and use separate identifiers
`dev.kartpad.rmcj01.ios` and `dev.kartpad.rmcj01.development`. RMCE01 (USA) is
not included.

## Installation

- macOS: Apple Silicon, macOS 14 or newer. Extract the ZIP and install the app.
  It is ad-hoc signed, not notarized with an Apple Developer ID certificate.
- iOS / iPadOS: version 16 or newer, ARM64. The IPA is unsigned and requires
  local signing with your own certificate and provisioning profile.
- Supply your own matching revision-0 game image or extracted DATA. Neither
  region's package contains a disc image or extracted game assets.
- Retro Rewind additionally requires the matching official pack.
- Keep the regions' saves and data separate. Do not replace a PAL executable
  with the Japanese executable inside an existing app bundle.

## Validation and limits

The source merge passed the complete Python contract suite: 176 tests ran,
175 passed and one private production-payload test was skipped because that
private payload is not cached. The repository safety audit also passed.

The Japanese release packages are rebuilt, region-audited and inspected for
private data before upload. The earlier user-accepted iPad/macOS validation and
assistant-observed Japanese Original / Retro Rewind evidence remain documented
in [the extended ledger](../RMCJ01-EXTENDED.md). This release pass does not
recharacterize that historical evidence as a new physical-device acceptance
run or as independent completion of every online multiplayer flow.

## Distribution boundary

These free community-preview apps contain ahead-of-time translated executable
logic, but no game image, extracted assets, Retro Rewind pack, saves, account
identity, device identifiers, private signing key or provisioning profile. The
iOS signature is removed; the Mac signature is ad-hoc. GPLv3 license text,
available third-party notices and provenance are included. See
`RIGHTS_AND_LICENSES.md` for the software license, Corresponding Source duties
and separate game-content rights boundary.

`SHA256SUMS` covers all four downloadable app archives. PAL assets preserve
their original upstream bytes; Japanese assets are packaged from the tagged
fork source without private signing or runtime state.
