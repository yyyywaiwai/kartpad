# KartPad 0.4.22 — ios

This release replaces the replayed WiiCompiled patch stack with maintained source and pinned platform branches. The upstream version and translated game behavior are unchanged. The existing KartPad repository, history and attribution are preserved.

Native source parity, generated-output comparisons, builds, package checks and rollback rehearsal passed. The owner accepted loading, running and starting games on the tested iPad and Android candidates; macOS reached a race in the host smoke check. Sustained race completion, broader device coverage and online race/reconnect are not new claims of this release.

The iPad reached Retro WFC using a new license. An existing license returned serial-mismatch error 22005 on both the previous and migration builds. That profile remains unresolved; this release does not reset identities or repair server registration history. Update in place and preserve saves and console identity. Raw save exports do not include console identity.

The existing iPhone/iPad Files-sharing settings remain enabled. Unfinished save/Mii export features are not included. Experimental tvOS has no new binary in this release.

See [migration validation](../source-maintenance/VALIDATION.md) and [source maintenance](../source-maintenance/README.md).
