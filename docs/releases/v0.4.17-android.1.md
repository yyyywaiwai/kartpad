# KartPad v0.4.17 Android 1

Choose **Display → FPS Counter Size → Small, Medium or Large** to resize the
FPS counter. Small remains the default and your selection is saved. This release
also improves the touch-control editor on narrow landscape screens. The selected control's Show/Hide and sizing
controls stay reachable without requiring an 800dp-wide panel (#238).

Right Shoulder can now map to D-pad Up for tricks and wheelies (#184), with safe
assignment swapping and migration of valid existing controller mappings.
The release also includes viewport-specific interpolation history and the
compiled REL-report guard, retaining Retro Rewind 6.12.8.

WFC menu latency, race-transition disconnects and sustained performance remain
unresolved. No license/identity reset or merging change is included; preserve
existing licenses.

## Validation boundary

The owner accepted Retro single-player racing and touch controls on private
code78. Private code79 additionally passed the Large HUD size, saved-size persistence
and touch D-pad Show/Hide checks on the physical Pixel. The final public
code80 release configuration is a separate artifact. Its debug-signed test twin
has 155 ZIP entries identical to the public APK and passed the emulator
selector check. Code80 was not installed on the physical phone after it
disconnected; the owner authorized release with that testing boundary disclosed.
Reporter-specific controller, completed-race and online acceptance remain separate.

Install over the existing public-signed application without uninstalling or
clearing data. Game images, extracted assets, saves and signing credentials are
not included. Supply your own supported game data.
