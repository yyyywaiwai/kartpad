# KartPad 0.4.14 — official iPhone and iPad update

Version **0.4.14, build 33**, for ARM64 iPhone/iPad on iOS/iPadOS 16 or newer.
This is the current official iPhone/iPad release, replacing the 0.4.13/build-29
preview. Android, macOS and experimental tvOS retain their separate packages.

## Changes

- A clearer Mario Kart Wii / Retro Rewind chooser shows whether game data and
  the optional pack are ready, with larger cards and a visible Help entry.
- The normal landscape iPhone chooser fits on one screen. Setup instructions,
  GitHub guides and version details are available in Help. Larger accessibility
  text can scroll instead of being reduced or clipped.
- Setup help explains importing the supported base game first and then adding
  the official Retro Rewind pack inside KartPad.
- Report a Problem uses shorter paragraphs and gives numbered instructions for
  attaching its diagnostic log to GitHub. Opening an issue does not upload it.
- Render resolution remains under Display and no longer appears in Touch
  Control Settings. Existing saved resolution and touch preferences are retained.
- Apple surface recreation reuses the SDL-owned Metal view, preserving its
  UIKit root and attached controls. This fixes a reproduced ownership defect;
  it is not blanket confirmation of wired-display or AirPlay recovery.
- Retains the generic ARM64 startup correction, console-serial correction and
  version-locked Retro Rewind 6.12.7 support from preceding releases.

## Update without losing data

Download `KartPad-v0.4.14-ios.1-unsigned.ipa` and `SHA256SUMS`, verify the checksum,
then re-sign and install over the existing app with the same signing identity
and bundle identifier. Back up first; do not uninstall or clear app data.
Use the [installation guide](../INSTALL_IPA.md).

Supply your own supported PAL (Europe) Mario Kart Wii RMCP01 revision 0 image.
The IPA includes translated logic, but no disc image, extracted retail assets,
Retro pack, saves, signing certificate or provisioning profile. Retro Rewind
content installs separately through the app.

## Validation and known limits

Christopher accepted the latest build-32 candidate on the physical M2 iPad and
requested this official release. Earlier in the same pass he reported smooth
60 FPS controller gameplay, working menus and good display modes on that iPad.
The build-32 update preserved all 32 protected files byte-for-byte. Build 33 is
rebuilt from merged source and changes the release version/build metadata.

The iPhone 17 Pro and iPhone SE native UI fixtures have no vertical overflow in
missing-data, ready and paused states. Native Help/Done, game callbacks and both
GitHub destinations were exercised. The full iOS app, unsigned bundle and public
IPA have separate build/package gates; see the
[release evidence](../artifacts/2026-09-09/ios-v0414-release.md).

The A10X reporter confirmed startup and Original/Retro loading in build 29,
but reported lower frame rates. A10X performance, affected-phone Fill Screen
reports, external displays/AirPlay, touch gameplay, custom controller remapping
and broader online/peripheral acceptance remain separate. This release does not
include PR #157's unaccepted viewport-interpolation change or Android's ongoing
performance experiments. No new general FPS improvement is claimed.
