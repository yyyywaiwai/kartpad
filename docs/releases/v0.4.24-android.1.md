# KartPad 0.4.24 Android 1 — code 117

The accepted mobile update brings consistent settings, Original Time Trial ghost transfers and better diagnostic reporting.

- Matching Android/iOS menu order and labels; Time Trial Ghosts is directly under Game Data & Saves.
- Original `.rkg` import/export, validation, backup and deferred application that preserves intervening save progress. Retro Rewind custom-track ghosts remain unsupported.
- Expanded D-pad/trigger mappings, optional shared actions and the Use L1 for Items preset.
- Small/Medium/Large FPS counters and a clearly named Android Graphics Diagnostics section.
- Improved runtime telemetry and private reports with bounded retained Android native-crash/ANR traces when the OS provides them. Private traces are excluded from public issue metadata.

Includes yesterday's racing K icon and launcher, dark mode by default, light-mode toggle, preferred-game selection, return-to-menu navigation, and license rename/Choose Mii repairs.

The owner accepted the private candidate's interface and game operation on Pixel 9 Pro XL. This public package rebuilds that source with the established public signing identity, code 117, and profiling disabled. CPU front-cache changes are included, but no controlled race result establishes a general FPS improvement. Device-specific crashes, geometry corruption, frame drops and existing online-identity failures remain open.

Update in place with the APK and download its notices/checksums. Do not uninstall or clear app data. Private developer-signed previews cannot be overwritten by the public signer without a separate backed-up migration.
