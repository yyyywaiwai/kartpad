# KartPad 0.4.22 source delivery

The shared source archive contains the clean Android compilation source at
42122cebbb6e0af4f4d803050f376996878548aa, all four maintained runtime gitlinks,
pinned upstream WiiCompiled and Dolphin snapshots, the exact prepared Android
runtime, dependency sources and reconstruction instructions. Its manifest binds
the public Android APK and verifies every delivered file.

The iOS executable was compiled at 43a1661a5c2cb6a5f545cf6e3aaeb330a6857456;
its original manifest and executable hash remain in the IPA. The production
source is equivalent except the explicit builder record-count validation
correction, whose generated outputs were independently compared. The Mac
production paths also match the tested source; signing and version metadata
are packaged separately. These are precise source/payload checks, not a claim
of a new independent bit-identical rebuild on another machine.

Game images, game assets, translated game functions, saves, console identities
and private signing keys are not included. Rebuild with your own supported
inputs and the delivered platform recipes. Dependency source archives were
retained from the reviewed prior delivery, their manifests checked, and all
nine CMake archive pins compared to the current runtime. The source archive's
REBUILD.md explains the layout and offline Git restoration.
