# KartPad Japan 0.8.0 — RMCJ01 preview

This fork-specific release is for Japanese **RMCJ01 revision 0**. It is separate
from the upstream PAL release and from PadMint's PAL-only recipe. The unsigned
iPhone/iPad IPA and ad-hoc-signed Apple Silicon Mac DMG contain translated game
logic but **no disc image, game assets, Retro Rewind archive, saves, console
keys, Apple certificate, private key or provisioning profile**. Supply your own
matching Japanese game data and obtain Retro Rewind from its official source.

## Changes

- Integrates upstream KartPad 0.8.0, including the current WiiCompiled runtime,
  update notices, app icon choices and Shake to Trick where supported.
- Targets Retro Rewind **6.13.1**. Obtain the official 6.13.0 full pack and
  apply the official 6.13.1 update before using the Japanese Retro mode.
- Keeps the Japanese app identities separate from the upstream PAL app.

## Downloads and installation

- `KartPad-v0.8.0-japan.1-RMCJ01-ios-unsigned.ipa`: iOS/iPadOS 16+, ARM64.
  Re-sign with your own certificate and provisioning profile. Install over
  an existing `dev.kartpad.rmcj01.ios` app using the same signing team to keep
  its data; do not uninstall it first.
- `KartPad-v0.8.0-japan.1-RMCJ01-macos-arm64.dmg`: Apple Silicon, macOS 14+.
  Ad-hoc signed, not Developer ID signed or notarized. Quit the old app and
  replace it; its user data is stored outside the app bundle.
- `KartPad-v0.8.0-japan.1-source.tar.gz` contains the pinned KartPad, runtime,
  translator and SunPad source. The iOS build scripts fetch pinned Dolphin
  DiscIO sources and apply the tracked platform shims. Check `SHA256SUMS`
  before using a download.

The generic [iPhone/iPad](../INSTALL_IPA.md) and [Mac](../INSTALL_MACOS.md)
instructions describe the upstream PAL/PadMint product; their PAL disc ID and
PadMint steps do **not** apply to this Japanese binary.

## Verification and limits

Release-specific package audit, device and Mac checks are recorded in this
release's GitHub notes. A package audit is not gameplay or online acceptance.
The isolated Mac build booted and reached a Japanese Luigi Circuit time trial;
the packaged DMG was mounted and its app passed the Japan app audit.
The clean 0.8.0 app was installed over the existing iPad app, with the save
file and app preferences unchanged by hash immediately afterward. Gameplay of
this release build was not retested. The earlier 0.8.0 development build
launched and showed both game cards, but its Retro Rewind data remained at
6.12.8; that is not a 6.13.1 gameplay result. No iPhone or Apple TV
acceptance is claimed.

are resolved. See `RIGHTS_AND_LICENSES.md` and `THIRD_PARTY_NOTICES.md`.
