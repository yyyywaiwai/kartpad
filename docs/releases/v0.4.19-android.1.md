# KartPad 0.4.19 for Android — code 85

This maintenance release includes three corrections from PR #271:

- **Original startup:** Original no longer runs recovery for the optional Retro Rewind installation. Malformed Retro installation state can no longer block Original at that recovery step.
- **Retro installation:** reopening the chooser during background extraction no longer lets recovery delete the active staging directory or interfere with activation. Recovery defers while another process owns the installation.
- **Packed vertex attributes:** the renderer reads three-byte attributes without unnecessarily fetching a fourth byte beyond their storage binding.

The previous D-pad, FPS-size, controller mapping, Preferred Game and continuation changes remain included.

## Validation and limits

The startup and install corrections passed real filesystem and separate-process tests, including recovery during extraction/activation, cancellation, interrupted-worker recovery, invalid paths and save preservation. Android Kotlin/Java compilation passed. The shader correction passed 2,048 boundary cases at two optimization levels with sanitizers and eight compute/draw checks through pinned Dawn on Mac, with 4,096 comparisons per check.

This is not a measured performance release. No fresh physical Android gameplay acceptance is claimed for code85. The shader boundary defect is corrected, but it is not established as the cause of all missing/stretched-character reports. Delayed native crashes, online endurance and device-specific graphics issues remain open.

## Focused checks

- If Retro installation previously failed when returning to the app, retry the normal supported installation flow and report whether it completes.
- If valid Original data was blocked by broken Retro installation state, try Original without deleting either profile.
- If characters were missing or stretched, compare the same character/track scene and report the device, installed code85, profile and whether the symptom changed. A negative result is useful; no broad settings sweep is needed.

Update in place over a Community-signed public installation. Do not uninstall, reset identities or clear saves. A differently signed private preview requires compatible packaging; do not uninstall to work around a signature mismatch.

The release includes the ARM64 APK, corresponding-source archive, notices and SHA256SUMS. Existing game inputs are still required. Apple downloads are unchanged.
