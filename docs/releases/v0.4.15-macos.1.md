# KartPad 0.4.15 for macOS

Build 34 brings the merged Metal surface lifetime correction to the macOS package. It keeps SDL ownership consistent when a Metal view is recreated. This does not establish that reported tearing, external-display behavior or a particular gameplay crash is fixed.

Requires Apple Silicon and macOS 14 or newer. The app is ad-hoc signed. It contains no game data; supply your own supported files through the existing setup.

The separate controller/keyboard settings work in PR #112 is not included. Existing macOS settings and reporting remain unchanged.
