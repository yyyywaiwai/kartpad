# Source and rebuild

This is an incremental iOS build, version 0.4.23 (46). The unchanged runtime and translated game objects come from the hardware-tested anonymous-memory build at commit `91aaedc7cff6c4e801cfe0636d5c3a4aa3b9bc2d`. The launcher and Mii manager are freshly compiled from the accompanying release source, and the new icon assets are compiled for both iPhone and iPad. It is not represented as a full compilation of the maintained-source migration.

`kartpad-build.json` retains the base compilation identity. `kartpad-ui-composition.json` records the refreshed source hashes, both new object hashes, the retained object hashes and final executable hash. The refresh tool checks the prepared runtime and translation fingerprints and the cached production files against the base revision before relinking. Public packaging checks the refreshed inputs against the release commit and rejects signing material, game data and private executable paths.

To reproduce the composition, build the base revision with its documented physical-iOS dual-product build workflow, your own supported game data and pinned dependencies. Retain the Xcode build log and object cache. Then, from the release source, run:

```sh
python3 scripts/refresh-ios-release.py \
  --base-repo /absolute/path/to/base-source \
  --base-build /absolute/path/to/base-xcode-build \
  --build-log /absolute/path/to/base-build.log \
  --base-runtime /absolute/path/to/base-prepared-runtime \
  --translation /absolute/path/to/your-generated-translation \
  --output /absolute/path/to/refreshed-build
```

The source delivery includes the recorded base source and prepared iOS runtime alongside current release source. Generated game translation and game data are not included. Different toolchains may produce different binary hashes; the exact-release package audit intentionally pins this published artifact. The base runtime and translation fingerprints are included in its provenance. See `docs/BUILDING.md` for dependencies and user-data preparation.

The combined release source archive is attached to the [0.4.23 Android release](https://github.com/chrissotraidis/kartpad/releases/tag/v0.4.23-android.1); it covers both mobile packages and this iOS base composition.
