🏁 **KartPad 0.4.24 is out for Android and iPhone/iPad!**

The last two days bring a new racing K icon and launcher, dark/light mode, preferred-game selection, working license rename/Mii repair, and consistent mobile settings menus.

Also new: **Original Time Trial `.rkg` import/export**, expanded controller/D-pad/trigger remapping, adjustable FPS counter size, safer save handling, and improved problem reports—including a fixed iPhone reporting layout.

Android performance work is still ongoing; this isn't a claimed FPS breakthrough. Custom Retro Rewind ghost transfers aren't supported yet. Please try the new features and report anything that breaks through **••• → Report a Problem**.
